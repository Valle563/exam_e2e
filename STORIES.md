# User Stories

## Navigering

- Som användare vill jag kunna navigera till Katalog så att jag kan se alla böcker
- Som användare vill jag kunna navigera till Lägg till bok så att jag kan lägga till en ny bok
- Som användare vill jag kunna navigera till Mina böcker så att jag kan se mina favoriter
- Som användare vill jag kunna navigera till Statistik så att jag kan se statistik

## Katalog

- Som användare vill jag se en lista med böcker så att jag kan välja favoriter
- Som användare vill jag kunna favoritmarkera en bok så att den sparas i Mina böcker

## Lägg till bok

- Som användare vill jag se ett formulär med Titel och Författare så att jag kan lägga till en ny bok
- Som användare vill jag kunna lägga till en ny bok så att den visas i katalogen

## Mina böcker

- Som användare vill jag se ett meddelande när inga böcker är valda så att jag förstår vad sidan är till för
- Som användare vill jag se mina favoritmarkerade böcker så att jag kommer ihåg vad jag vill läsa
- Som användare vill jag kunna favoritmarkera flera böcker så att alla visas i Mina böcker

## Statistik

- Som användare vill jag se hur många böcker som finns i listan
- Som användare vill jag se hur många böcker som hjärtmarkerats
- Som användare vill jag att antalet hjärtmarkerade uppdateras när jag markerar en bok
